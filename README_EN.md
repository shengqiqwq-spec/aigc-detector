# AI Text Detector & Humanizer

[中文](README.md) | **English**

A **fully-local** toolkit for AIGC (AI-generated content) text detection and humanization, with a model matrix scaling from phones to desktops.

---

## ✨ Highlights

- **4 model tiers**: 2MB (mobile) → 14MB (universal), auto-selected by hardware
- **Chinese detection F1 = 0.9834** (leak-free grouped split, 5,753 held-out samples; 99.27% on long text)
- **Bilingual**: auto-detects language and switches models automatically
- **100% local**: no network, no API cost, no data upload
- **Zero-hallucination humanizer**: programmatic n-gram audit, never alters facts/numbers
- **Multi-accelerator**: CPU / Intel Arc GPU (Vulkan) / Intel NPU (OpenVINO)

## 🚀 Quick Start

```bash
# 1. Install dependencies (only scikit-learn and friends needed)
pip install -r requirements.txt

# 2. Detect text (auto language detection + auto tier selection)
python src/model_zoo.py "your text here"

# 3. Check recommended tier for your machine
python src/model_zoo.py --info
```

## 🔍 Reading the Output

```json
{"language": "en", "ai_probability": 0.943, "bucket": "高", "confidence": "高(长文本~99.6%)"}
```

- `ai_probability`: AI probability from 0 to 1
- `bucket`: High (≥0.7) / Medium (0.3-0.7) / Low (<0.3)
- `confidence`: confidence hint based on text length

**Not a verdict** — this is a probability, not evidence.

## ⚠️ Known Limitations

1. **Short text is weaker**: <50 chars carries too little signal — inherent ambiguity (information-theoretic ceiling)
2. **It recognizes "model fingerprints"**: highly accurate on real Qwen/GPT output (86-100%), but human imitations of AI style may slip through
3. **New models require retraining**: AI models keep evolving; the detector must be retrained with fresh data
4. **Not equivalent to Turnitin**: an independent metric, cannot match any commercial detector's exact percentage
5. **English short text is conservative**: lands in "Medium" rather than "High"

## 🤝 Technical Notes

### Why TF-IDF instead of Transformers?

Measured on CPU: roberta-base takes 33 s per training step (44 min for 80 steps) — completely impractical.
Switched to character-level TF-IDF + logistic regression: **trains in 68 s, with higher F1** (0.9834).

### Why mix in Qwen-generated data?

HC3 is 2022 GPT-3.5 style — it performs poorly on modern model output (English only 0.05).
After mixing 1,860 modern Chinese + 888 modern English AI texts generated by local Qwen:
- Chinese modern-AI detection: 96.7%
- English fixed from 0.05 to **0.9939**
