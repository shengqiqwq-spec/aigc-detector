# 使用指南

## 一、安装

```bash
pip install -r requirements.txt
```

检测功能**只需要 numpy**（四个档位都带纯 numpy 快路径，加载不走 sklearn）。
**不需要 GPU/NPU**，也不需要联网。

## 二、检测

```bash
# 单条检测（自动判断语言、自动选档位）
python src/model_zoo.py "你的文本"

# 查看你的机器适合哪档
python src/model_zoo.py --info

# 指定档位
python src/model_zoo.py "文本" --tier tier0

# 各档基准测试
python src/model_zoo.py --benchmark
```

## 三、准确率预期

分组防泄漏切分的真实 F1（同一问题的问答不跨训练/测试集）：

| 文本长度 | 中文 F1 | 英文 F1 | 建议 |
|---|---|---|---|
| 长（>200 字） | **0.9896** | 0.9835（>1500 字符） | ✅ 最可靠 |
| 中（80–200 字） | **0.9775** | 0.9956（500–1500 字符） | ✔ 较可靠 |
| 短（<80 字） | **0.9626** | 0.9731（<500 字符） | ⚠ 中等 |
| **40 字以下** | — | — | ⚠ 概率会被主动拉向 0.5 |

（中文整体 F1 **0.9814**，英文整体 **0.9905**，均为分组防泄漏独立集）

**核心建议：检测 150 字以上文本最可靠，长文本 F1 约 0.99。**

⚠️ 但**文体比长度更影响准确率**。同一长度下，说明文/论述文识别很好，
而「实用指南」「企业宣传文案」这类**内容具体、不堆套话**的 AI 文本，
即使很长也可能漏判——因为模型学的是措辞特征，不是"AI 味"。详见
[README 的文体覆盖表](../README.md#-模型矩阵)。

## 四、怎么看结果

```json
{"ai_probability": 0.887, "bucket": "高", "confidence": "高(长文本 F1~0.99)"}
```

- `ai_probability`：0~1 的 AI 概率
- `bucket`：高(≥0.7) / 中(0.3-0.7) / 低(<0.3)
- `confidence`：根据文本长度给出的置信度提示

**不要当判决书**：这是概率，不是证据。

## 五、降 AI 率

### 方案一：规则改写（零依赖）

```bash
python src/humanize2.py "你的文本"
```

### 方案二：程序化引擎（零幻觉，保事实）

```bash
python src/evasion_engine.py "你的文本"
```

包含 n-gram 审计、零宽字符清理、不改数字/专名。适合不能改动事实内容的场景。

### 方案三：LLM 改写（效果最强）

需要本地 llama.cpp + GGUF 模型：

```bash
# 1. 启动 llama-server（见 start_llama_server.bat）
# 2. 改写
python src/humanize_llm.py "你的文本"

# 3. 自动迭代到目标分
python src/humanize_auto.py "你的文本" --target 0.3 --max-loop 3
```

## 六、什么场景准 / 不准

### 准
- 学生论文、课程作业（长文本、书面语）
- 官方公告、报告
- 标准 ChatGPT/Qwen/DeepSeek 风格输出

### 不准
- **短句/口语**（聊天、微博、短评）
- **高度公式化文本**（法律条文、技术手册 — 人也写得机械）
- **人机混合改写**（AI 初稿 + 人工润色）
- **人类刻意模仿 AI** 的文本

## 八、诚实声明

1. **这不是 Turnitin**：独立指标，无法对齐商业检测器精确百分比
2. **检测会失效**：AI 模型持续进化，检测器需重训
3. **不要用于正式指控**：误判率虽低但不是 0
4. **仅供研究学习**，不得用于学术不端

## 九、重要：检测器识别的是什么

**实测发现**：
- 真实 Qwen/GPT 生成的文本：**73-97% 能识别**（平均概率 0.79-0.96）
- 人类手写的"AI 风格"模仿：**识别率低**（0.18 左右）

**结论**：检测器识别的是**特定大模型的实际用词指纹**（如"首先/其次""值得注意的是""综上所述"的具体组合模式），不是抽象的"AI 感"。

**这意味着**：
1. 检测真实 AI 生成的文本 → 准
2. 检测人类模仿 AI 的文本 → 可能漏判（因为用词习惯不同）
3. 换一个新的 AI 模型 → 需要重新生成数据训练

**正确用法**：把检测器当成"特定模型指纹识别器"，而不是"AI 感检测器"。
