# 下载下来怎么玩

三条路，从快到慢。**都只需要 numpy**，不用装 torch、不用 GPU、不用联网。

---

## 0. 拿到东西

两种方式，选一个：

**A. 直接下压缩包（最省事）**

打开 https://github.com/shengqiqwq-spec/aigc-detector/releases/latest
点 `aigc-detector-x.y.z.zip`，解压，进去。

**B. 会 git 就 clone**

```bash
git clone https://github.com/shengqiqwq-spec/aigc-detector.git
cd aigc-detector
```

需要 **Python 3.9 以上**（3.11/3.12/3.14 都验过）。检查一下：

```bash
python --version
```

装依赖（只有 numpy 一个是真需要的）：

```bash
pip install -r requirements.txt
```

> 模型已经打包在 `ckpt/` 里，**不需要下载任何权重，不需要训练**。

## 1. 最快：命令行跑一句

```bash
python src/model_zoo.py "这里粘贴要检测的文本"
```

输出是一段 JSON，重点看两个字段：

```json
{
  "language": "en",
  "tier": "en",
  "ai_probability": 0.6181,
  "bucket": "中",
  "confidence": "中(80-200字 F1~0.98)"
}
```

- `ai_probability` — AI 概率，0~1
- `bucket` — 高（≥0.7）/ 中（0.3~0.7）/ 低（<0.3）
- `confidence` — 按长度给的可靠性提示，**短文本会自动收缩到 0.5 附近并标注"仅供参考"**

不传参数会打印机型画像和可选档位：

```bash
python src/model_zoo.py --info
```

### 调 API

```bash
curl -X POST http://127.0.0.1:8000/detect \
  -H "Content-Type: application/json" \
  -d '{"text": "Artificial intelligence has fundamentally transformed modern society."}'
```

Python 里调：

```python
import json, urllib.request

def detect(text):
    body = json.dumps({"text": text}, ensure_ascii=False).encode("utf-8")
    req = urllib.request.Request(
        "http://127.0.0.1:8000/detect", data=body,
        headers={"Content-Type": "application/json; charset=utf-8"})
    with urllib.request.urlopen(req) as r:
        return json.loads(r.read())

print(detect("人工智能技术正在深刻改变各行各业的发展格局。"))
```

### ⚠️ Windows 用户会踩的坑

**在 cmd / PowerShell 里用 curl 发中文，大概率报这个：**

```
{"error": "'utf-8' codec can't decode byte 0xd7 in position 9"}
```

不是你输错了，是 Windows 控制台按 GBK 编码发送，服务端按 UTF-8 解析。
三种解法，任选：

1. **把 JSON 存成 UTF-8 文件再用 curl 读**
   ```bash
   # req.json 用记事本另存为 UTF-8
   curl -X POST http://127.0.0.1:8000/detect -H "Content-Type: application/json" -d @req.json
   ```
2. **用上面的 Python 片段**（已指定 `charset=utf-8`，最稳）
3. **直接用网页 Demo**，不用碰编码

## 3. 想直接写在代码里

```python
import sys
sys.path.insert(0, "src")
import model_zoo as M

M.warm_up()                      # 可选: 预热, 让第一次调用不是冷的

d = M.detect("要检测的文本")       # 自动判语言、自动选档
print(d["ai_probability"], d["bucket"])

d = M.detect("some english text", tier="en")   # 也可以指定档位
```

可用的档位（`--info` 会告诉你本机推荐哪个）：

| 档位 | 体积 | 说明 |
|---|---|---|
| `tier1` | 2.6MB | 中文主力，F1 0.9814 |
| `en` | 5.3MB | 英文主力，F1 0.9899 |
| `tier3` | 1.9MB | 中文极速 CNN，**需要装 torch** |
| `tier0` | 421KB | 中文轻量，手机/树莓派 |
| `en_tier0` | 357KB | 英文轻量 |

## 5. 它到底能信多少

跑通了先看这一段，别拿它当 Turnitin。

**擅长**（实测 F1 0.99 上下，误报 0.2~0.4%）：

- 议论文、技术说明、问答体、社媒口语 —— 靠句式套路和虚词堆砌的 AI 文本

**不擅长**（大面积漏判，实测 0/6）：

- 产品参数介绍、影评、旅游攻略、学术摘要、公文 —— 靠具体名词和数字撑起来的文本

**原因**：它用的是字符级 TF-IDF + 逻辑回归，只认训练里见过的 token。
一段文本要是每句都是 AMOLED、ResNet-50、洱海这类具体名词，模型眼里等于"没见过"。

**所以**：

- 可以用来做初筛、批量看趋势
- **不能当学术诚信判定依据**
- 40 字以下不可靠（接口自己会标注）
- 代码 / JSON / HTML 会被明确拒绝，不会瞎给分数

## 6. 常见问题

**Q: 报 `ModuleNotFoundError: No module named 'numpy'`**
→ `pip install numpy`，就这一个必须的。

**Q: 报端口占用**
→ `python src/serve.py --port 8123`

**Q: 中文在命令行里显示乱码**
→ Windows 终端执行 `chcp 65001` 切到 UTF-8，或者用 `启动Demo.bat`（它自己会切）。

**Q: 想自己重训模型**
→ 看 `scripts/` 目录和 `docs/训练日志_2026-11-20.md`。注意重训需要 sklearn，
而发布出去的是纯 numpy 的 `fast.npz`，重训完要跑 `scripts/export_fast.py` 转换。

**Q: 能不能不装 Python**
→ 目前不能，这是纯 Python 项目。最轻的用法只需要 numpy 一个包。
